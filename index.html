AI application checklist and improvement feedback

Core features to verify

  • AI answers questions and shows a useful error when the service is unavailable.
  • Camera and uploaded files are actually read; unreadable scans are clearly identified.
  • Each answer can be copied or downloaded as PDF, Word, PowerPoint, or Excel.
  • Phone layout, keyboard navigation, loading state, and empty-input validation work.

Important before public launch

  • Keep GROQ_API_KEY only in Netlify environment variables; never in browser code or GitHub.
  • Add rate limiting and abuse protection before sharing widely to control API costs.
  • Publish a privacy notice explaining whether prompts/files are sent to the AI provider and how long data is retained.
  • Test with blurry photos, large files, long prompts, no internet, invalid API keys, rate limits, and mobile browsers.
  • Monitor function errors and provider usage; set budget/usage alerts where available.
  • Give users a way to report wrong answers and remind them to verify important information.

Current status: These are a checklist, not a claim that every item has been tested. Browser-side downloads and the live Netlify/API connection must be verified after deployment.
